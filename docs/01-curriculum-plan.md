## 1. 전체 스토리라인

"AI는 어떻게 등장했고, 왜 지금 이렇게 빠르게 발전하고 있으며, 앞으로 우리에게 어떤 변화를 가져올까?"

OPENING(호기심) → PART1(큰 그림: 역사·트렌드) → PART2(원리: 어떻게 작동하나) → BREAK(직접 체험)
→ PART3(실전: 함께 일하는 법) → PART4(하이라이트: Agent·바이브코딩) → CLOSING(역할·Q&A)
