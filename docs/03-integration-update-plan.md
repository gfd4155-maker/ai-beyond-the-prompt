# 통합 업데이트 계획 (Integration Update Plan)

이 저장소에는 "인터랙티브 요구사항 적용 이전"의 별도 기획안이 존재하지 않았습니다(최초 기획 단계).
따라서 커리큘럼 기획과 인터랙션 기획을 **처음부터 하나로 통합**해 아래 두 문서로 확정했고, 중복 작업 없이 1회로 마무리합니다.

- 커리큘럼·슬라이드 구성: `01-curriculum-plan.md`
- 인터랙션 8항목 설계: `02-interaction-design-plan.md`

## 1. 반영 요약

- 전체 120분 구조(OPENING~CLOSING, BREAK 포함)는 원 요구사항의 7개 섹션·시간 배분을 그대로 유지했습니다.
- 인터랙션은 장식이 아니라 `01-curriculum-plan.md`의 특정 슬라이드 번호(예: 1-7, 2-3, 2-7, 3-3, 3-4, 4-1, 4-4, 4-5)에 직접 매핑되어, "설명만으로 이해하기 어려운 지점"에만 배치했습니다.
- 인터랙션 총 10개(INT-00~INT-09)로 "8~12개" 범위를 충족하며, 요청에서 우선시한 9개 개념(발전 타임라인/AI·ML·DL/다음 토큰 생성/프롬프트 개선/RAG/Chatbot vs Agent/Agent Workflow/AI 결과 검증/제조업 AI 활용)을 모두 포함합니다.
- 전역 원칙(설계 원칙 1~7)은 모든 인터랙션 설계에 공통 적용됨: 계정/설치 불필요, 사전 데이터 기반, 강의 후 자유 체험 가능(BREAK의 Playground 및 전체 사이트 상시 접근), 실제 AI 연산이 아님을 각 화면에 명시.

## 2. 이번 범위에서 실제로 구현한 것

우선순위 3개 화면을 실제 동작하는 코드로 구현했습니다 (`src/` 참조).

1. **INT-00 용어 도움말 ON/OFF** — 전역 Glossary Mode (기본값 OFF, 중앙 데이터 파일 1곳에서 용어 관리)
2. **INT-03 Chatbot vs AI Agent 비교** — 모드 전환/단계 이동/자동재생/비교보기 전체 기능
3. **INT-06 프롬프트 개선 시뮬레이터** — 좌/우/하 3분할 레이아웃, 요소 누적 선택, Before/After 비교모드

나머지 7개(INT-01, 02, 04, 05, 07, 08, 09)는 `02-interaction-design-plan.md`에 설계가 확정되어 있으며, 동일한 공통 컴포넌트(ControlBar, GlossaryTerm, FlowNode/FlowEdge)를 재사용해 다음 단계에서 구현 가능합니다.

## 3. 공통 발표 운영 기능(요구사항 9번) 적용 현황

구현된 3개 화면 모두 다음 공통 컨트롤을 포함합니다 (`src/components/common/ControlBar.tsx`):

- 이전 단계 / 다음 단계, 초기화, 자동재생/일시정지(해당되는 화면만), 발표자 노트 열기/닫기, 전체화면 전환, 핵심 포인트 보기
- 키보드 단축키(←/→)는 인터랙션 컨테이너에 포커스가 있을 때만 동작하며, 텍스트 입력 필드(프롬프트 편집 영역) 포커스 중에는 비활성화되어 슬라이드 탐색과 충돌하지 않습니다.
- 각 화면은 React state를 URL/컴포넌트 상태로만 유지하고 세션 간 영속시키지 않습니다 — 다른 화면으로 이동 후 돌아오면 항상 초기 상태로 복원되어, "조작 후 이탈해도 깨지지 않는다"는 요구를 깨끗한 리셋 방식으로 만족시킵니다. Glossary ON/OFF 설정만 `localStorage`에 저장해 재방문 시에도 유지합니다(발표자 편의).

## 4. 다음 단계 제안 (이번 범위 밖)

- INT-04(토큰 생성), INT-05(RAG), INT-07(검증 게임) 구현 — PART2/PART3 완성에 필요
- INT-01/02/08/09 구현 — 나머지 섹션 완성에 필요
- PHASE 2(디자인 시스템 토큰 정리), PHASE 4(콘텐츠·발표자 대본 전량 작성), PHASE 5(QA), PHASE 6(배포)는 원 기획서의 단계 정의를 그대로 유지하며 착수하지 않았습니다.
